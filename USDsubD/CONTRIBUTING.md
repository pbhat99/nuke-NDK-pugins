# Contributing to USDSubD

Thanks for your interest in contributing! Here's how to get started.

## Reporting Issues

- Search existing issues first to avoid duplicates.
- Include your Nuke version, OS, and a minimal repro scene if possible.

## Pull Requests

1. Fork the repo and create a feature branch from `main`.
2. Keep changes focused — one feature or fix per PR.
3. Make sure the plugin compiles cleanly on your platform before submitting.
4. Write a clear PR description explaining *what* and *why*.

## Code Style

- C++17, consistent with the existing codebase.
- Use the Nuke NDK / USG APIs as documented by Foundry.
- Prefer clarity over cleverness.
